# Security Policy

## Supported versions

Security fixes are provided for the latest released version of UsageBar.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Use
[GitHub private vulnerability reporting](https://github.com/OsakanaForge/usage-bar/security/advisories/new)
and include:

- the affected version and environment;
- reproduction steps or a proof of concept;
- the potential impact; and
- any suggested remediation.

Reports will be acknowledged as soon as practical. Please allow time for a fix
and release before public disclosure.
